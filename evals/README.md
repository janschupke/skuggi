# skuggi evals

A committed, **local-only** evaluation system for the agent. Nothing is ever
uploaded: every Braintrust `Eval` runs with `no_send_logs=True`, and the baseline
lives in git, not in a cloud project.

## Two tiers

| Tier | Dimensions | Oracle | Runs |
|------|-----------|--------|------|
| **deterministic** | `compliance`, `methodology`, `schema`, `result_compat` | skuggi's own pure functions (`check_command`, `clamp_phase`, the protocol schemas, the ledger + report) | default test suite + `skuggi-eval --tier det`; **hard-gates CI** |
| **quality** | `factuality`, `budget`, `latency` | `autoevals.Factuality` (LLM judge), token cost, wall-clock | `skuggi-eval` / `make bench`; needs a provider; **never blocks CI** |

The deterministic tier is Braintrust-free on purpose: importing `braintrust`
pulls in `langsmith`, which warns under Python 3.14, and the suite runs
warnings-as-error. The Braintrust benchmark is the quality tier only.

## Layout

- `scopes.json` — reusable engagement scopes referenced by `scope_ref`.
- `goldens/<dimension>.json` — the curated cases (`{dimension, description, cases}`).
- `baseline.json` — per-dimension `{score, threshold, provider}`; the gate floor.
  A `null` score means "not yet baselined" — gated on `threshold` alone.
- `prices.json` — a dated snapshot of the token prices behind the budget dimension.
- `scorecard.md` — regenerated by `make bench` (per-dimension × provider vs baseline).

## Commands

```sh
skuggi-eval --tier det --check          # offline gate: score deterministic dims vs baseline
make bench                              # full benchmark across providers (costs money)
skuggi-eval --tier all --update-baseline  # rewrite baseline.json (review the diff before commit)
```
